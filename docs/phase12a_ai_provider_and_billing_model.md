## 1. 商家是否需要自己配置 AI API？

| 用户类型 | 是否需要自带 Key | 说明 |
|----------|------------------|------|
| **普通商家（Starter / Growth）** | **否** | 注册即用；只关心「还能回多少条」 |
| **高级商家** | 可选 | 设置页「高级 · 使用自己的模型 Key」 |
| **企业版（Pro / Enterprise）** | 可选 + 推荐 | 私有模型、VPC、自有网关、合规审计 |

**对外话术：** 「我们提供 AI 能力，您专注店铺规则与审核；技术配置由平台负责。」

**避免：**  onboarding 要求填写 OpenAI/火山 Key（会吓跑中小商家、推责给商家）。

---

## 2. 三种 AI 供给模式

| 模式 | ID | 适用 | 计费 |
|------|-----|------|------|
| **平台托管 AI** | `platform_hosted` | **默认** | 含在套餐 AI 条数额度内 |
| **自带 API Key** | `byok` | 高级设置 | 套餐费降低或仅收平台费；AI 费用由商家自担 |
| **私有模型 / 企业网关** | `enterprise_private` | 企业合同 | 定制报价 + SLA |

```text
请求路径（平台托管）:
  商家店铺 → 平台 AI Gateway（限流、审计、脱敏）
           → 上游模型（火山/OpenAI/自建，对商家不可见）
           → 返回 suggested_reply → Preview / Send gate
```

---

## 3. 平台托管 AI 设计要点

| 项 | 说明 |
|----|------|
| **模型选择** | 平台按场景选默认模型；商家只选「语气/长度」不选 model id |
| **密钥管理** | 平台统一 KMS；商家不可见 |
| **审计** | 日志存摘要；训练 opt-out 政策在 ToS 写明 |
| **降级** | 主模型失败 → 备用模型；仍失败 → 商家可见提示 |
| **成本控** | 套餐 AI 条数封顶 + 速率限制 |

---

## 4. 自带 API Key（BYOK，非 MVP 默认）

| 项 | 说明 |
|----|------|
| 入口 | 设置 → 高级 → 「使用自己的 AI Key」 |
| 校验 | 保存时测试调用；失败不可启用 BYOK |
| 计费 | 套餐可标「平台费 only」；AI 用量不计入平台额度 |
| 风险 | 商家 Key 泄露责任条款；平台仍做禁诺/日志 |

---

## 5. 企业私有模型

| 能力 | 说明 |
|------|------|
| 专用 endpoint | 商家 VPC 或指定区域 |
| 模型版本锁定 | 合同约定 |
| 数据不出境选项 | 合规套餐 |
| SSO + 审计导出 | Pro/Enterprise |

**Phase：** 13+ 商务驱动，非 MVP。

## 7. 异常与提示（商家文案）

### 7.1 AI 服务失败

| 场景 | 商家提示 | 系统行为 |
|------|----------|----------|
| 上游超时 | 「AI 暂时繁忙，请稍后；本条已转人工提醒」 | 不发送；记 `failed_reason=ai_timeout` |
| 上游 4xx/5xx | 「AI 服务异常，我们已收到告警」 | 不发送；可选重试 1 次 |
| 内容审核拒绝 | 「该回复未通过安全审核，请人工处理」 | 拦截 + 日志 |

### 7.2 AI 额度不足

| 场景 | 商家提示 | 系统行为 |
|------|----------|----------|
| 月度条数用尽 | 「本月 AI 额度已用完；Preview 仍可查看历史 / 升级套餐」 | 停止 **新** AI 生成或仅 Preview 旧会话 — **推荐：停止新生成** |
| 接近上限（90%） | 站内 + 邮件预警 | — |

### 7.3 连接 vs AI 失败

须区分 **店铺掉线** 与 **AI 失败**，避免商家误以为「被封号」。

## 8. 套餐与 AI 额度（与 pricing 对齐）

| 套餐 | 平台托管 AI | BYOK | 私有模型 |
|------|-------------|------|----------|
| Starter | ✅ 低额度 | ❌ | ❌ |
| Growth | ✅ 中额度 | 可选 | ❌ |
| Pro | ✅ 高额度 | ✅ | 商务 |

**计费维度（AI 相关）：**

- **AI 建议/回复条数 / 月**（主计量，对齐成本）
- **自动发送条数**（可单独 cap，控制风险）
- 店铺数、成员数、日志保留 — 见 mvp_scope doc

## 10. 结论摘要

| # | 结论 |
|---|------|
| 1 | 普通商家 **不需要** 自己配置 AI API |
| 2 | **平台托管 AI** 为默认 |
| 3 | AI 成本 **打包进套餐**，商家看额度 |
| 4 | BYOK / 私有模型 = **高级 & 企业**，非 MVP |
| 5 | 失败与额度不足须 **明确、可行动** 的商家提示 |
