## 1. 产品原则（不可妥协）

| 原则 | 说明 |
|------|------|
| **绑定 ≠ 自动回复** | 店铺连接成功只表示「能收/能发」，不开启 AI 自动发送 |
| **默认 Preview** | 新绑定店铺默认 **Preview / Dry-run**（见 safety spec） |
| **开启自动发送须二次确认** | 勾选风险须知 + 确认当前规则已配置 |
| **一键暂停显眼** | 全局 + 单店；Dashboard 顶部固定 |
| **PDD MVP 优先** | 抖店/淘宝/京东展示 **即将支持 / 预约内测**，不对外承诺已接店 |
| **平台托管 AI** | 普通商家 **不需要** 自己填 API Key（见 ai_provider doc） |

---

## 2. 目标用户与首次价值

| 用户 | 首次「啊哈」时刻 |
|------|------------------|
| 单店老板 / 主客服 | 在 Preview 里看到「这条买家消息 AI 会这样回」，且觉得靠谱 |
| 小团队 | 一人配规则，多人看日志、点暂停 |

**不是**首次价值：绑定后立刻全自动、消息秒回（易引发信任危机）。

## 3. 完整 Onboarding 流程

```text
① 注册 / 登录
     手机号 + 验证码 / 企业微信（后期）
     → 创建「工作区」（组织名、行业可选）

② 欢迎页（价值主张）
     「AI 副驾驶：先预览回复，您确认后再自动发」
     → CTA：添加第一家拼多多店铺

③ 选择平台
     [拼多多] 可点击
     [抖店] [淘宝] [京东] 灰显 + 「即将支持 · 预约内测」

④ 绑定店铺（PDD）
     见 shop_binding_playbook
     → 授权 / 登录向导
     → 展示将获得的权限（收消息、发消息、会话列表）

⑤ 连接检测（必过才进下一步）
     ✓ 授权有效
     ✓ 能收到测试探针 / 最近 5 分钟有心跳
     ✓ 发送权限探测（可选：向测试会话发一条系统消息）
     失败 → 停留在「修复连接」，不进入 Preview

⑥ 默认进入 Preview / Dry-run
     横幅：「当前仅生成建议，不会自动发给买家」
     → 引导配置最小规则集（可跳过但推荐）

⑦ 配置向导（可折叠，建议 5 分钟内完成）
     - **AI 可回答范围**（默认：仅售前咨询 — 商品/规格/库存/FAQ/活动/基础发货说明/推荐）
     - 店铺欢迎语（可选）
     - 3–10 条 FAQ（售前向）
     - 禁诺规则（默认模板已勾选）
     - 转人工关键词（默认：转人工、退款、投诉…）
     - 回复语气（亲切 / 专业 / 简短）

⑧ 观察期（建议 copy 写进产品）
     「建议先观察 24–72 小时 AI 建议，再开启自动发送」
     → Dashboard：今日建议数、采纳数、拦截数

⑨ 查看 AI 建议回复
     会话列表 / 回复日志
     每条：买家问 · **intent 分类**（咨询类 / 售后类 / 不确定 / 已转人工）· AI 建议 · 状态（仅预览 / 已发送 / 已拦截 / 转人工）

⑩ 显式开启自动发送（二次确认）
     弹窗：
       - 当前模式：Preview → 将改为 Auto（或 Assisted）
       - 风险勾选：「我理解 AI 可能出错，已配置禁诺与转人工」
       - [取消] [确认开启]
     → 记录审计：谁、何时、从哪种模式切换

⑪ 日常运营
     Dashboard · 日志 · 异常 · 用量
     一键暂停随时可用

⑫ 付费升级
     额度将尽 / 需要多店 / 需要审核发送 → 套餐页
```

## 4. 各步骤界面要点

### 4.1 注册 / 工作区

| 元素 | 说明 |
|------|------|
| 工作区名称 | 默认「我的店铺」可改；代运营可「XX 客户组」 |
| 角色 | 所有者 / 管理员 / 客服（只读日志）— Growth+ |
| 无技术项 | **不出现** API Key、Webhook、环境变量 |

### 4.2 绑定成功页（非开启自动回复）

文案示例：

> 店铺已连接。自动回复当前为 **仅预览模式**，买家不会收到 AI 消息。  
> 您可以在「回复日志」中查看 AI 会怎么回。

主按钮：**去查看 AI 建议**  
次按钮：**配置规则**  
**不要**放「立即开启自动回复」作为主 CTA。

### 4.3 开启自动发送确认页

商家须勾选并确认（二次确认弹窗）：

| 确认项 | 文案要点 |
|--------|----------|
| **咨询范围** | 我理解 AI **只自动处理低风险售前咨询**（商品、规格、库存、FAQ 等） |
| **售后转人工** | 我理解 **售后 / 退款 / 投诉 / 赔偿 / 改单改址** 等问题将 **转人工**，不由 AI 自动发送承诺性回复 |
| **Preview 建议** | 我已先观察 Preview 建议（推荐 24–72h） |

| 检查项 | UI |
|--------|-----|
| 已配置 FAQ ≥ 1 | ✓ / 警告 |
| 禁诺已启用 | ✓ 必须 |
| 转人工词 ≥ 1 | ✓ 必须 |
| **AI 可回答范围已确认** | ✓ 必须（默认售前咨询） |
| 连接状态正常 | ✓ 必须 |
| 过去 24h 无大量拦截 | 建议项 |

### 4.4 一键暂停

| 层级 | 位置 | 行为 |
|------|------|------|
| **全局** | 顶栏红色「暂停全部自动回复」 | 所有店停止 Auto/Assisted 发送；Preview 可继续生成建议（可配置） |
| **单店** | 店铺卡片开关 | 仅该店停止发送 |

暂停后 Banner：**已暂停 — 买家消息不会收到 AI 自动回复**（直至您恢复）。

## 6. 与当前工程差距

| Onboarding 步骤 | 当前代码 |
|-----------------|----------|
| 商家 SaaS 注册 | ❌ 桌面本地 |
| 工作区 / 租户 | ❌ |
| PDD 绑定 | ⚠️ 账号管理 + Playwright（非 SaaS OAuth） |
| Preview 模式 | ❌ 产品 flag/UI |
| 二次确认开启 | ❌ |
| 一键暂停（产品级） | ⚠️ 停止线程，无全局语义 |

→ 实现见 Phase **12b–12d**。

详见 [phase12b1_product_messaging_update.md](phase12b1_product_messaging_update.md)。

**一句话：** 拼多多售前咨询 AI 副驾驶 — 先预览，再自动发；退款投诉等转人工，随时可暂停。
