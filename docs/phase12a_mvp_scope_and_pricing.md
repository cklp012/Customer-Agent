## 1. MVP 一句话

**帮拼多多商家在正式自动回复买家之前，先看见 AI 会怎么回、拦截 risky 内容、随时一键暂停 — AI 由平台提供，无需自己配 API。**

---

## 2. MVP 应包含

| 类别 | 功能 |
|------|------|
| **平台** | 仅 **PDD** 可绑店、可收消息、可（在模式下）发送 |
| **绑定** | PDD 店铺绑定 + 授权状态 + 连接健康（见 binding playbook） |
| **模式** | **Preview / Dry-run 默认**；Growth 试用可开 Assisted/Auto |
| **安全** | 禁诺模板、转人工词、低置信转人工、一键暂停（全局+单店） |
| **内容** | FAQ、欢迎语（基础）、语气预设 |
| **可观测** | 回复日志（建议/发送/拦截/原因）、今日概览 |
| **AI** | **平台托管**；用量/额度展示 |
| **计费** | Starter 试用 + 升级 Growth；计量 AI 条数 |
| **多平台** | 抖店/淘宝/京东 **waitlist UI only** |

---

## 3. MVP 不应包含

| 排除项 | 原因 |
|--------|------|
| 绑定即 **默认全自动** | 信任风险 |
| **真实 Doudian** production | 未接 API |
| 淘宝 / 京东 production | 未调研绑定 |
| 自动退款 / 改价 / 改地址执行 | 纠纷与合规 |
| 完整 CRM / 工单 / 外呼 | 范围蔓延 |
| **商家默认自配 AI API** | 吓跑 SMB |
| 复杂订单引擎 | 后期 |
| 无预览的批量群发 | 骚扰风险 |

---

## 4. 套餐设计（三档）

### 4.1 Starter（获客 / 试水）

| 维度 | 内容 |
|------|------|
| 店铺数 | 1 |
| AI 建议条数 / 月 | 500–2,000 |
| 自动发送 | **❌ 或** 试用 7 天限量 100 条（须显式开启） |
| 模式 | **Preview only** |
| 成员 | 1 |
| 日志保留 | 7 天 |
| 平台托管 AI | ✅ |
| BYOK | ❌ |

**目标：** 让商家 **敢试** — 零自动发送风险。

### 4.2 Growth（主力 ARPU）

| 维度 | 内容 |
|------|------|
| 店铺数 | 3–5 |
| AI 条数 / 月 | 10,000–30,000 |
| 自动发送 | ✅ 配额内；Assisted + Auto |
| 模式 | Preview → 可切换 Auto（二次确认） |
| 成员 | 3 |
| 日志保留 | 30 天 |
| 禁诺 + 转人工 | 完整 |
| BYOK | 可选（高级设置） |

### 4.3 Pro（代运营 / 团队）

| 维度 | 内容 |
|------|------|
| 店铺数 | 20+（可增购） |
| AI 条数 / 月 | 100,000+ |
| 自动发送 | ✅ + **审核队列**（Assisted 默认） |
| 成员 / 权限 | RBAC、操作审计 |
| 日志保留 | 90 天 + 导出 |
| BYOK / 私有模型 | 商务 |
| SLA | 可选 |

---

## 5. 计费维度（推荐组合）

| 维度 | 权重 | 说明 |
|------|------|------|
| **店铺数** | 高 | 商家心智清晰 |
| **AI 回复/建议条数** | **最高** | 对齐平台成本 |
| **自动发送能力** | 中 | Starter 无 / Growth 有 — 差异化 |
| **成员数** | 中 | Pro 卖点 |
| **日志保留** | 低 | 套餐阶梯 |
| **平台数** | MVP 不计 | 等多平台再收「平台包」 |

**不推荐单独按「消息进线量」计费**（商家难理解且与 AI 成本弱相关）；可作为 **封顶保护**。

---

## 6. 免费试用 → 付费转化

| 阶段 | 策略 |
|------|------|
| 注册 | 14 天 Growth 功能试用 |
| 试用默认 | **Preview**；自动发送需手动开 + 上限 100 条 |
| 转化触发 | 额度 80%、第 7 天、首次拦截帮商家「避坑」文案 |
| 降级 | 过期回 Starter Preview only |

---

## 7. 售卖叙事 vs 工程现实

| 对外说 | 工程现状（11h） |
|--------|-----------------|
| PDD AI 副驾驶 | PDD 生产路径 ✅ |
| 先 Preview | ❌ 产品未实现 |
| 多平台 | mock only，**waitlist** |
| 平台 AI | 本地 config，**非** SaaS Gateway |

**Gap 关闭顺序：** 12b 租户/绑定 → 12c Preview → 12d Dashboard → 12f 计费。
