## 1. 绑定后状态机（全平台统一）

```text
未绑定 → 授权中 → 已连接 → 健康检查中 → 就绪（Preview 默认）
                ↓           ↓
            授权失败    收消息异常 / 发消息异常 / 授权过期
                ↓
            需重新授权（商家可见原因 + 操作按钮）
```

**与自动回复模式正交：** 连接「就绪」≠ Auto 开启。

| 状态字段 | 商家可见文案 |
|----------|--------------|
| `auth_status` | 未授权 / 已授权 / 即将过期 / 已过期 |
| `inbound_health` | 正常 / 超过 N 分钟无消息 |
| `outbound_health` | 正常 / 发送失败率过高 |
| `reply_mode` | 仅预览 / 确认后发送 / 自动发送 |
| `paused` | 已暂停（全局或本店） |

## 2. 绑定方式对比（总表）

| 方式 | 商家体验 | 技术难度 | 合规 | 封号风险 | 凭证安全 | SaaS 推荐 |
|------|----------|----------|------|----------|----------|-----------|
| **OAuth / 官方授权** | ⭐⭐⭐⭐⭐ 一键、可续期 | 中–高（资质+审核） | ⭐⭐⭐⭐⭐ | 低 | 高（token+scope） | **首选** |
| **扫码登录（官方 SDK/页）** | ⭐⭐⭐⭐ 熟悉 | 中 | ⭐⭐⭐⭐ | 中低 | 中–高 | **可用** |
| **子账号 / 客服账号授权** | ⭐⭐⭐ 需理解权限 | 中 | ⭐⭐⭐⭐ | 低 | 高 | Growth+ |
| **账号密码** | ⭐⭐ 怕泄露 | 低–中 | ⭐⭐ | 中–高 | **差** | **不推荐对外** |
| **Cookie / 会话导入** | ⭐ 技术向 | 中 | ⭐⭐ | 高 | 差 | **仅过渡** |
| **Playwright / 爬虫** | ⭐ 非 SaaS 感 | 高维护 | ⭐ | **高** | 差 | **仅内部过渡** |

## 3. 分平台分析

### 3.1 拼多多（PDD）— MVP 平台

| 方式 | 说明 | 评估 |
|------|------|------|
| **开放平台 OAuth**（若 scope 覆盖 IM） | 标准 SaaS | **中长期主路径**；需调研可用 API 与资质 |
| **扫码登录（商家后台）** | 商家熟悉 | 可作为 OAuth 补充 |
| **账号密码 + Playwright**（**当前工程**） | 本地 `pdd_login` | **过渡方案**：不对商家宣传「官方合作」；凭证须加密、会话刷新、掉线提示 |
| **子账号** | 主账号授权子客服 | 代运营场景；权限边界文档化 |

**PDD MVP 建议路径：**

1. 短期：托管连接器 + 强化安全存储 + 状态 Dashboard（包装 Playwright 为「安全连接向导」，不提爬虫）  
2. 中期：迁移 **官方 OAuth**（G9 黄金路径不退化）  

**风险话术（对内）：** 密码存 DB、封号、会话失效 → 必须在 12b 设计 vault + 过期 UX。

### 3.2 抖店（Doudian）— 未来，非当前售卖

| 方式 | 说明 | 评估 |
|------|------|------|
| **抖店开放平台 OAuth** | 企业资质、应用审核 | **唯一推荐**对外路径 |
| **飞鸽 IM API** | 与开放平台可能分离 | G1 调研；可能决定 inbound/outbound |
| 账号密码 / 非官方 | — | **禁止**作为售卖方案 |

**当前：** mock spike（10k–11g）**不等于**可绑店；商家侧 **waitlist only**。

### 3.3 淘宝（Taobao / 千牛）

| 方式 | 说明 | 评估 |
|------|------|------|
| **千牛 ISV / 淘宝开放平台** | 审核周期长 | 第三优先级 |
| 桌面插件 + 扫码 | 安装率低 | 不推荐 MVP |

**售卖：** 仅展示「规划中」，不接绑定流程。

### 3.4 京东（Jingdong / 京麦）

| 方式 | 说明 | 评估 |
|------|------|------|
| **京东开放平台 OAuth** | 相对标准 | 第四优先级（可与淘宝并行调研） |
| 京麦客户端依赖 | 集成重 | 后期 |

## 4. SaaS 绑定向导（产品设计，PDD 模板）

```text
步骤 1：选择平台 [拼多多]
步骤 2：说明权限（收消息、发消息、查看会话 — 人话列表）
步骤 3：跳转官方授权 / 安全登录（不出现「把密码给我们」为主文案）
步骤 4：回跳 → 自动健康检查
步骤 5：成功 → 进入 Preview（非自动发送）
```

**重新授权：** 过期前 7 天提醒；过期后 Dashboard 红色条 + 一键重新授权。

## 6. 明确结论

| 结论 | 说明 |
|------|------|
| **对外售卖** | 官方 OAuth / 授权为主；体验与合规可辩护 |
| **Playwright/密码** | 仅过渡；文档与营销 **不得** 作为主卖点 |
| **Doudian** | 未 production；waitlist |
| **绑定成功** | 默认 Preview；见 onboarding UX |
